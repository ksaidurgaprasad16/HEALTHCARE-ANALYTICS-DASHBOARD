# Healthcare Analytics Dashboard

## Project Overview
This project is an end-to-end healthcare data analytics solution developed using Excel, Python, and Power BI. The project focuses on data cleaning, exploratory data analysis (EDA), dashboard development, and generating actionable business insights from healthcare data.

The workflow includes:
- Raw data preprocessing using Excel
- Data cleaning and EDA using Python
- Interactive dashboard development using Power BI
- KPI analysis and healthcare performance monitoring

---

## Tools & Technologies
- Excel
- Python
- Pandas
- NumPy
- Matplotlib
- Power BI
- Power Query
- DAX

---

## Project Workflow

### 1. Data Collection & Preprocessing
- Imported raw healthcare dataset
- Removed duplicates
- Handled missing values
- Performed initial formatting and preprocessing using Excel

### 2. Python Data Analysis
- Conducted Exploratory Data Analysis (EDA)
- Generated summary statistics
- Identified trends and patterns
- Created visualizations using Matplotlib

### 3. Power BI Dashboard Development
- Built relational data model using one-to-many relationships
- Created 10+ DAX measures and KPIs
- Developed interactive multi-page dashboards
- Added slicers, filters, KPI cards, and YoY analysis

---
